# MTX Project — Vercel Deployment

هذه الحزمة مهيأة لتشغيل المشروع كتطبيق **Flask API** على Vercel باستخدام وظيفة Python serverless.

## طريقة الرفع

ارفع محتويات هذا المجلد كما هي إلى مشروع جديد في [Vercel Dashboard](https://vercel.com/new). اترك **Framework Preset** على `Other`، واترك **Build Command** و**Output Directory** فارغين، ثم اضغط **Deploy**. يجب أن يكون ملف `vercel.json` في جذر المشروع، وليس داخل مجلد فرعي.

## المسارات بعد النشر

إذا كان رابط المشروع هو `https://your-project.vercel.app`، فالمسارات المتاحة هي:

| المسار | الاستخدام |
|---|---|
| `/` | معلومات الخدمة وحالتها |
| `/get?uid=123456789` | جلب معلومات اللاعب |
| `/status` | حالة الرموز والحسابات المحملة |
| `/stats` | إحصاءات الواجهة |
| `/refresh` | تحديث رمز الدخول |
| `/clear_cache` | مسح ذاكرة الاستجابات |

## ملاحظات مهمة

يحتوي `acc.txt` على بيانات تشغيل حساسة، لذلك لا ترفع هذا المشروع إلى مستودع عام ولا تشارك محتوى الملف. لا يوجد مفتاح Vercel داخل هذه الحزمة؛ أدخل مفتاحك من حسابك عند الرفع أو استخدم لوحة Vercel مباشرة.

تمت إضافة `api/index.py` كنقطة دخول متوافقة مع Vercel، وإضافة تهيئة للتطبيق عند التشغيل serverless. التخزين المؤقت داخل Vercel مؤقت وغير مضمون بين الطلبات أو عمليات التشغيل، وهو سلوك طبيعي في بيئات serverless.

قبل استخدام المشروع على نطاق عام، يُنصح بإضافة مصادقة للمسارات التي تغيّر الحالة مثل `/refresh` و`/clear_cache`، وتقييد الوصول إلى `/status` حتى لا تظهر معلومات الحسابات وحالة الرموز للعامة.
